# HTML & CSS Multi-Page Website

A simple, semantic, and responsive multi-page website built with HTML and CSS.

## ✨ Features

* Responsive design
* Clean and simple layout
* Multiple pages
* Semantic HTML structure
* Responsive breakpoints
* Image assets

## 📄 Pages

* Home
* About
* Services
* Contact

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Getting Started

Open `index.html` in your browser to view the website.

## 📌 Purpose

This project was created to practice HTML and CSS fundamentals, responsive layouts, and multi-page website development.
